# Ожидаемая сводка времени

Правило склейки: события с паузой между соседними ≤ N минут — один рабочий
блок; пауза больше — блок закрылся на последнем событии.

При **N = 10 мин**: блоки 09:00–09:05, 09:41–09:44, 11:10–11:59, 14:00–14:03
→ **~56 минут** активной работы.
При **N = 40 мин**: первые два блока склеиваются (пауза 36 мин) → 09:00–09:44,
11:10–11:59, 14:00–14:03 → **~96 минут**.

Ключевая проверка: сводка отдаёт ОБА расчёта и явно показывает выбранный порог —
чувствительность к N видна, цифра без порога не выдаётся (боль заказчика:
«разброс от одного параметра»).
