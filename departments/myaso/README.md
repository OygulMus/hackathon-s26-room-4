# 🥩 Мясо · Рыба · Курица

Руководитель отдела: **Денис (4NNT)**. Issue #17.

## Что тут лежит

`data/*.json` — недельные снимки цен в контракте v2. Дашборд кухни
(`python3 -m core.kitchen`) собирает отдел по ним автоматически.

Два источника, и они отвечают на разные вопросы.

## 1. Росстат — российский рынок, недельная история

```bash
python3 -m parsers.rosstat departments/myaso/data
```

Файл `rosstat.gov.ru/storage/mediabank/Nedel_sred_cen.xlsx` — еженедельные
средние потребительские цены по России, листы по годам, колонки по неделям.
Рубли за килограмм.

Живой прогон, неделя 17.08 → 24.08:

```
Говядина (кроме бескостного мяса)   752.04 → 751.02 ₽   −0.14%
Свинина (кроме бескостного мяса)    402.61 → 402.91 ₽   +0.07%
Баранина (кроме бескостного мяса)   819.59 → 818.56 ₽   −0.13%
Куры охлаждённые и мороженые        261.44 → 262.72 ₽   +0.49%
Рыба мороженая неразделанная        371.69 → 373.19 ₽   +0.40%
```

⚠ **Про сертификат, и это стоит знать всей комнате.** У `rosstat.gov.ru`
сертификат выдан «Russian Trusted Sub CA» — российским государственным
удостоверяющим центром, которого нет в системном хранилище доверенных.
Обычный запрос обрывается на проверке и возвращает `http=000`. Мы сначала
приняли это за блокировку по стране и написали в отчёте, что госсайты закрыты
для зарубежных адресов — **это было неверно**. Сайт открыт, не проходит только
проверка сертификата. Проверка здесь отключается осознанно: источник публичный,
мы только читаем открытую статистику и ничего не отправляем.

Отдельно: `zakupki.gov.ru` действительно не отвечает на TCP — вот он закрыт
по-настоящему.

## 2. Еврокомиссия — эталон динамики

```bash
python3 -m parsers.eu_agri departments/myaso/data poultry beef pigmeat
```

`ec.europa.eu/agrifood/api/<товар>/prices?memberStateCodes=HR&years=2026` —
без ключа и регистрации, чистый JSON. Работают `poultry`, `beef`, `pigmeat`,
`sugar`, `rawMilk`; `eggs`, `cereals`, `fruitAndVegetable` отвечают 404.

Живой прогон, неделя 16.08 → 23.08, евро за 100 кг:

```
ГОВЯДИНА  коровы          528.00 → 460.00   −12.9%
          бычки           675.84 → 625.31    −7.5%
          тёлки           641.74 → 601.29    −6.3%
ПТИЦА     филе грудки     709.93 → 680.50    −4.1%
          окорочка        263.02 → 276.23    +5.0%
СВИНИНА   pigmeat         131.61 → 135.15    +2.7%
```

Здесь глубокие движения, и именно на них видно, зачем нужен зелёный класс из
issue #25: четыре падения, одно на 12.9%, и до правки не подсвечивалось ни
одно.

## Почему два источника, а не один

Росстат отвечает на вопрос «что происходит с ценой на российском рынке» —
это рынок заказчика. Еврокомиссия отвечает на вопрос «как выглядит заметное
движение» — там амплитуда больше, и по ней удобно проверять, что пороги
и подсветка вообще работают.

## Что здесь НЕ решено

Ни один из двух источников не даёт **прайс конкретного поставщика**. Оба —
средние по рынку. Закупщику нужно «у кого сегодня дешевле», а такой цены
в открытом доступе нет ни в России, ни в ЕС: проверено на восьми источниках,
отраслевые порталы прячут таблицы за регистрацией, B2B-площадки не отдают
цену по позициям.

Прайс поставщика приходит файлом в почту — поэтому вход инструмента для
закупщика это не сайт, а файл. Модуль `parsers/pricelist.py` читает такой
прайс (CSV или Excel) и превращает в снимок того же контракта. Это ответ на
настоящую боль, но он требует хотя бы одного реального файла от поставщика,
а его у нас сегодня нет.
