# ⚙️ Отдел «Оборудование кухни» — Кирилл

Ты — руководитель отдела закупки. Категория: кухонное оборудование: мясорубки, слайсеры, печи, холодильники.
Эта папка — твоя целиком: источники, код, дизайн — на твой вкус.
Общий план: `docs/plan-kitchen.md`. Единственное жёсткое требование —
формат снимков (контракт v2), по нему дашборд кухни соберёт твой отдел.

## Стартовый промпт для твоего агента (нулевая точка — скопируй целиком)

```text

репозиторий ai-mindset-org/hackathon-s26-room-4, концепция «Кухня ресторана».

Моя роль: руководитель отдела закупки «Оборудование кухни» ресторана.

проверяют цены поставщиков (~100 SKU, ~9 человеко-часов в день).

стоп-лист), ≥5% — жёлтый.

Моя задача до 13:00 CET:
1. Выбрать 3–8 реальных позиций категории «кухонное оборудование: мясорубки, слайсеры, печи, холодильники»
   и 1–3 доступных источника цен (идеи: klenmarket.ru, complexbar.ru, restoranoff, авито (опыт парсинга есть)).
   Источник, который не отдаётся (403/капча/заглушка) — тоже результат,

что появилось/пропало, какие источники сегодня недоступны.
```
