# Варианты стиля

## 1. Product demo — рекомендуется

Светлая схема с заметным пользовательским результатом: закупщик быстро видит
дайджест и принимает решение. Хорошо подходит для хакатонного демо.

## 2. Executive signal

Минимум декоративности, крупные блоки, один акцент на рисках: подорожание,
недоступный источник и ручное решение. Хорошо для обсуждения с заказчиком.

## 3. Dark operations

Тёмный операционный стиль с явными потоками данных и веткой ошибки источника.
Хорошо показывает техническую надёжность, но слабее подчёркивает продуктовую
пользу.
