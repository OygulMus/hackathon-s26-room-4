## Правила отдела

1. Папка отдела — твоя целиком: источники, код, дизайн странички — на твой вкус.
2. **Снимки цен — в `departments/<отдел>/data/*.json` в контракте v2** (см. ниже).
   Это единственное жёсткое требование: по нему дашборд собирает твой отдел.
3. Страничка отдела (если делаешь) — `departments/<отдел>/index.html`,
   дашборд сам подхватит и слинкует.
4. Стартовый промпт для агента лежит в `departments/<отдел>/README.md` —
   нулевая точка, дальше веди как хочешь.

## Контракт снимка v2 (issue #4, реализован в core/)

```json
{"taken_at": "2026-08-29T12:00:00", "source": "домен-источника",
 "source_status": "ok|unreachable",
 "items": {"sku-или-артикул": {"shop": "магазин", "title": "название",
   "price": 129.0, "currency": "RUB",
   "price_status": "listed|on_request|unknown", "in_stock": true}}}
```

Честность: источник не ответил → `source_status: unreachable` (это НЕ «пропало»);
цена-заглушка / «по запросу» → `price_status: on_request`.
Пороги заказчика: рост ≥10% — красный флаг, ≥5% — жёлтый.

## Проверка своего отдела локально

```bash
python -m core.build --data departments/<отдел>/data          # дайджест отдела
python -m core.kitchen                                         # пересобрать дашборд
```
