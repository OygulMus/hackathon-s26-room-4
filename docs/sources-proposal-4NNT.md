# Предложение: набор источников для мониторинга · 4NNT

Закрывает открытый вопрос из `docs/interview-SQSU.md` (PR #2):
«список конкретных сайтов с роботами для парсинга (2–5 штук)».

**Как проверено.** Каждый источник открыт лично сегодня, 29.08.2026,
10:42–10:53 CET, обычным `curl` с браузерным User-Agent; отдельно прогнан
поиск по рынку через Exa. Цены — fast-moving факт: числа ниже верны на
момент снятия и не переносятся на завтра без нового снимка.

## Что проверялось

Не «есть ли на сайте цены», а три вещи по каждому источнику: отдаётся ли
страница роботу вообще, лежит ли цена в машиночитаемом виде, и можно ли
по ней отличить «цена изменилась» от «цены нет».

## Результат

| Источник | Как берётся | HTTP | Валюта | Вердикт |
|---|---|---|---|---|
| `shop.unitree.com/products.json` | Shopify JSON | 200 | USD | **ядро.** 30 позиций, цена + наличие, парсер не нужен |
| `robotopian.com/products.json` | Shopify JSON | 200 | USD | **ядро.** 250 позиций, есть не-Unitree гуманоиды |
| `robotsinternational.com/Unitree.htm` | HTML | 200 | USD | **берём.** цены в вёрстке, есть «Special Price» |
| `crkphotoimaging.com.au/robotics/humanoids` | HTML | 200 | **AUD** | **берём.** другая валюта — нужен тест на нормализацию |
| `generationrobots.com/en/278-humanoid-robots` | HTML | 200 | EUR | берём при запасе времени |
| `robotshop.com/collections/humanoid-robots` | — | **403** | — | **не парсится.** оставить как кейс «источник недоступен» |

Итого пять рабочих плюс один заведомо недоступный. Рекомендую взять первые
четыре: два JSON-источника дают быстрый зелёный тест, два HTML-источника
кормят модуль `parsers/` реальными ловушками.

## Шесть ловушек, найденных в живых данных

1. **Цена-заглушка.** У `shop.unitree.com` позиции A2, H2-Plus, B1, B2 стоят
   ровно `100000.00`, а H1 называется буквально
   «Unitree H1（Contact us for the real price）» при цене `90000.00`.
   Это не цена, а «спросите нас». Принять за число — получить фальшивый
   обвал на 80% в первом же дайджесте.
2. **Разные валюты.** `crkphotoimaging` торгует в AUD: G1 Basic там `38 720`
   против `13 500` USD у вендора. Без нормализации сравнение магазинов
   выдаёт разницу в три раза на ровном месте.
3. **Одно имя — разные товары.** «G1» существует как Standard, EDU U2…U10,
   Comp, Boxing Edition, EDU Ultimate D. Сравнивать надо по ключу
   позиции магазина (handle / артикул), а не по названию модели. Это тот же
   принцип «по парт-номерам», что в исходной боли про диски.
4. **Зачёркнутая цена.** `robotsinternational` показывает
   «Special Price $37,500» рядом с `$39,900` — ровно ловушка примера 02,
   только на живом сайте.
5. **Наличие ≠ цена.** У Unitree H1, H2, A2 цена есть, но `available=false`;
   у австралийца встречается «ETA: 24/09/2026». Пропажа из наличия и
   изменение цены — два разных события, их нельзя складывать.
6. **Источник недоступен.** `robotshop.com` отдаёт 403 роботу. Если такое
   молча превратить в «позиция пропала», дайджест соврёт. Нужен третий
   статус, отличный от «есть» и «нет».

## Что из этого следует для контракта снимка

В плане распила (PR #2) контракт записан как
`{date, items: {ID: {shop, price, in_stock}}}`. Он не переживёт ловушек 1, 2 и 6.
Предлагаю добавить три поля:

```json
{
  "taken_at": "2026-08-29T10:42:00",
  "source": "shop.unitree.com/products.json",
  "source_status": "ok",
  "items": {
    "unitree-g1": {
      "shop": "shop.unitree.com",
      "title": "Unitree G1",
      "price": 13500.0,
      "currency": "USD",
      "price_status": "listed",
      "in_stock": true
    }
  }
}
```

- `currency` — иначе магазины несравнимы;
- `price_status`: `listed` | `on_request` | `unknown` — отделяет цену от заглушки;
- `source_status`: `ok` | `unreachable` — отделяет «источник лёг» от «позиция пропала».

Без этих трёх полей приёмочный пример 01 пройдёт на синтетике и развалится
на живых данных.

## Доказательство

`docs/evidence-4NNT/snapshot-unitree-2026-08-29.json` — реальный снимок,
снятый сегодня: 30 позиций с ценой и наличием. Второй снимок берётся той же
командой ближе к демо, и комната показывает настоящую динамику, а не
синтетическую.

Повторить снимок:

```bash
curl -s -A 'Mozilla/5.0' 'https://shop.unitree.com/products.json?limit=250'
```

## Что прошу у комнаты

1. Утвердить набор источников (четыре рабочих + robotshop как кейс отказа).
2. Принять три поля в контракт снимка до того, как `parsers/` и `diff/`
   разойдутся в разные стороны.
3. За мной модуль `timelog/` (пример 03) — критерий приёмки в PR #1.
