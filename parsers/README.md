```

regard.ru               459 510 RUB  в наличии: да
onlinetrade.ru                   —   недоступен: капча, тело 1871 байт

```

Один и тот же диск, один парт-номер: **702 596 против 459 510 — разница 52.9%**.

## Четыре ловушки, ради которых модуль существует

1. **NBSP.** `32&nbsp;100&nbsp;₽` — обычный `int()` на такой строке падает.
2. **Зачёркнутая цена.** Рядом лежат `price-new` и `price-old`. Взять старую —
   показать завтра несуществующий рост.
3. **«Ожидается поставка».** Текст о наличии есть, товара нет.
4. **Цена-заглушка.** «По запросу» и `100000` у Unitree — не число.
   `price_status: on_request`, в сравнение не идёт.

## Пятая ловушка — отказ источника, и он не один

Успех определяется **не кодом ответа, а наличием цены в теле**:

| Магазин | Что отдаёт | Почему нельзя верить коду |
|---|---|---|
| onlinetrade.ru | HTTP **200**, тело 1.8 КБ | формально успех, данных нет |
| kns.ru | HTTP 200, капча по IP | то же самое, но с текстом |
| citilink.ru | HTTP 429 | честный отказ, единственный |

Слово `captcha` встречается и в скриптах нормальных витрин, поэтому маркер
засчитывается только на короткой странице — иначе рабочий `xcom-shop`
ошибочно объявляется недоступным (поймано на живом прогоне).

Недоступный источник даёт `source_status: unreachable` и **пустой список
позиций**. Пустой список при `ok` означал бы, что все товары пропали из
выдачи — ложь, из-за которой дайджест покажет несуществующую катастрофу.

## Интерфейс

```python
from parsers.cards import parse_card      # HTML карточки → позиция
from parsers.shops import scrape          # живая страница → (позиция, статус)
from parsers.snapshot import build_snapshot

snap = build_snapshot("regard.ru", [item])          # контракт v2
snap = build_snapshot("kns.ru", [], status="unreachable")
```

`core.snapshot.normalize()` читает результат без адаптера — проверено тестом.
